ネットワーク上のホスト、開放ポート、サービス情報を調査するためのツール。

## 概要

- ホストの発見
- 開放ポートの確認
- サービス・バージョンの特定
- NSEスクリプトを使った追加調査

## よく使うコマンド

### 基本スキャン

```bash
nmap <target>
```

よく使われるポートを対象に、基本的なスキャンを行う。

### サービス・バージョン調査

```bash
nmap -sV <target>
```

開放ポートで動作しているサービスと、そのバージョンを確認する。

### スクリプトを含めた調査

```bash
nmap -sC -sV <target>
```

標準NSEスクリプトとサービス検出をまとめて実行する。CTFや検証環境での初期調査に便利。

### 全ポートの確認

```bash
nmap -p- -sV <target>
```

TCPポートを全件確認する。時間がかかるため、必要に応じて実行する。

## Writeupに残す項目

- 対象のIPアドレスまたはホスト名
- 実行したコマンド
- 開放ポートとサービス名
- バージョン情報
- 次の調査につながった発見事項

## メモ

対象システムのスキャンは、許可を得た環境でのみ実行する。
