## 1. Target Information（対象情報）
Machine : Linux

Platform : Vulnhub

Difficulty : Easy

Target IP : 192.168.56.4

Goal : root権限の取得

## 2. Reconnaissance（事前調査）
対象マシンのIPアドレスを特定
```bash
netdiscover -r 192.168.56.0/24
```
スクリーンショットを貼る

## 3. Enumeration（列挙）

### 3.1 Port Scanning
公開されているポートとサービスの確認
```bash
nmap -Pn -sS -sV 192.168.56.4
```
スクリーンショットを貼る

### 3.2 Directory Enumeration
ディレクトリ・サブドメイン探索の探索
```bash
gobuster dir -u http://192.168.56.4 -w /usr/share/wordlists/dirb/common.txt
```
スクリーンショットを貼る

### 3.3 Web Vulnerability Scanning
既知の脆弱性を調査
```bash
nikto -h http://192.168.56.4
```
スクリーンショットを貼る

### 3.4 SMB Enumeration
SMBのバージョンを把握していないため、調査

Nmapによるバージョン調査
```bash
nmap -p139 -sV --version-all 192.168.56.4
```
スクリーンショットを貼る

enum4linux-ngによるバージョン調査
```bash
enum4linux-ng -A 192.168.56.4
```
スクリーンショットを貼る

MetasploitによるSMBバージョン調査
```bash
msfconsole
msf6 > search smb_version
msf6 > use auxiliary/scanner/smb/smb_version
msf6 auxiliary(scanner/smb/smb_version) > set RHOSTS 192.168.56.4
msf6 auxiliary(scanner/smb/smb_version) > show options
msf6 auxiliary(scanner/smb/smb_version) > run
```
スクリーンショットを貼る

以上によるバージョンの特定は出来なかった。
なのでwiresharkで通信を傍受してパケットの確認
```bash
smbclient -L 192.168.56.4 -p 139
```
スクリーンショットを貼る

## 4. Vulnerability Identification（脆弱性の特定）
SMBのバージョンが判明、Samba 2.2系の既知の脆弱性を調査
```bash
searchsploit samba 2.2
searchsploit -x 10
searchsploit -m 10
```
Exploitのソースコードを取得
スクリーンショットを貼る
## 5. Exploitation（攻撃・侵入）
取得したExploitのコンパイル
```bash
gcc 10.c -o RCE
```
古くコンパイルの失敗
スクリーンショットを貼る

Metasploit Frameworkを使用してSamba 2.2系のExploitを検索
```bash
msfconsole 
search samba 2.2
```
